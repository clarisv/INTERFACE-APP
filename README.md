## 🚀 Como testar localmente

1. Clone o repositório e execute `npm install` na pasta do projeto.
2. Certifique-se de que o arquivo da tela que deseja testar esteja nomeado exatamente como `App.tsx`.
3. Execute `npx expo start` e escaneie o QR Code no aplicativo Expo Go.
